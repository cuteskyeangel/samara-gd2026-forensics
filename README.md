# Электоральная форензика: Самарская область, выборы в Государственную Думу (20.09.2026)

Поучастковый статистический анализ результатов выборов по одномандатным округам №159–163: 1703 УИК, выгруженных из ГАС «Выборы».

> ⚠️ Статистические аномалии — признаки, дающие основания для сомнений и официальных запросов, но не юридические доказательства. Данные предварительные.

## Методика

Девять статистических тестов на поучастковых данных: 100%-я и «вылизанная» явка, «полки» результата, 100% за кандидата, нулевые недействительные при высокой явке, символические «1 голос» оппозиции, дубли абсолютных чисел между УИК, выбросы внутри ТИК, корреляция «% × явка». УИК с хотя бы одним срабатыванием попадает в реестр. Пороги с поправкой на множественные сравнения (Бонферрони). Подробности — в [отчёте](https://cuteskyeangel.github.io/samara-gd2026-forensics/report.html).

## Основные находки (кратко)

- Двухсекторная структура: город (явка 35–50%, недействительные 4–6%) vs село (явка 78–95%, медианные недействительные 0,00%); сводная корреляция «% × явка» частично — артефакт бимодальности.
- «Полки» 80/85/90/95% статистически значимы в №161 и №162 (Бонферрони).
- Тест T7: 270 УИК с явкой ≥85% и ровно нулевыми недействительными.
- 140 случаев «ровно 1 голос» у оппозиции при ожидании ~0,4.
- Контрфактический пересчёт (без аномальных УИК): победа всех пяти лидеров сохраняется; наименьший запас — №160 (~4,1 тыс. голосов).

## Ограничения данных

22 файла выгрузки ТИК Алексеевская (№159) — сводки чужой кампании, исключены; файл УИК 3363 отсутствует. Итоговые протоколы на момент выгрузки не утверждены — при публикации окончательных данных данные будут обновлены.
